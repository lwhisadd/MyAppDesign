# 第二部分：正式每日下載功能規格

> 適用範圍：`Twitch下載/` 獨立專案。  
> 功能階段：第二部分。  
> 功能狀態：規格已建立；等待 `TWITCH_CHANNEL_SOURCES` 填入並通過驗證後才可啟用。  
> 目的：定義 Hermes 在第一次 bootstrap / preflight / runner / dry-run 通過後，如何執行正式每日 Twitch VOD 下載、去重、畫質檢查、報告產出與通知。  
> 建立日期：2026-08-09  
> 建立時區：Asia/Taipei

---

## 1. 結論

本文件定義本專案的第二部分功能：

```text
正式每日 Twitch VOD 下載
```

第二部分只在以下條件全部成立後才可啟用：

1. Hermes 已完成第一次 bootstrap。
2. PI16G001 preflight 通過。
3. runner 已產生且可執行。
4. dry-run 通過。
5. Hermes 既有 Discord 通知能力可用。
6. output root 可用。
7. 剩餘空間高於 1GB。
8. `TWITCH_CHANNEL_SOURCES` 已填入至少一筆來源。
9. 所有啟用來源都是 `authorization_status: "user_confirmed"`。
10. 來源中沒有 secret、token、cookie 或 password。

若上述任一條件不成立，Hermes 不得執行正式下載。

---

## 2. 第二部分不包含什麼

第二部分不包含：

1. 第一次 bootstrap。
2. 第一次 dry-run。
3. 實際 Twitch 頻道來源的填寫。
4. Twitch chat 下載。
5. clips 下載。
6. highlights 下載。
7. live recording。
8. 自動刪除已下載影片。
9. 降低到 480p 或更低畫質。
10. 保存任何 secret。

以上項目若未來要啟用，必須新增或修改專門文件。

## 4. 啟用條件

第二部分啟用前，Hermes 必須確認：

```yaml
PHASE_2_ENABLEMENT_CHECKLIST:
  first_execution_completed: true
  first_execution_status: "ready_for_channel_sources"
  bootstrap_passed: true
  preflight_passed: true
  runner_exists_and_executable: true
  dry_run_passed: true
  notification_runtime_available: true
  output_root_available: true
  free_space_above_1gb: true
  channel_sources_non_empty: true
  all_enabled_sources_user_confirmed: true
  no_secret_in_sources: true
  real_download_allowed: true
```

只要任一項不是 `true`，Hermes 不得正式下載。

---

## 5. 來源驗證規則

Hermes 必須從主設定檔讀取：

```yaml
TWITCH_CHANNEL_SOURCES
```

正式下載時，只能納入同時符合以下條件的來源：

```yaml
source_filter:
  enabled: true
  authorization_status: "user_confirmed"
  source_type_allowed:
    - "channel_videos"
    - "single_video"
```

若清單為空，回報：

```text
requires_user_input_channel_sources_empty
```

若所有來源都被停用或未確認，回報：

```text
blocked_no_enabled_user_confirmed_sources
```

若來源中疑似包含 token、cookie、password 或其他 secret，回報：

```text
blocked_secret_detected_in_channel_sources
```

Hermes 不得自行搜尋、猜測或新增來源。

## 6. 正式任務流程

第二部分每日正式任務流程如下：

```text
讀取必讀文件
  ↓
確認第二部分啟用條件
  ↓
取得 TWITCH_CHANNEL_SOURCES
  ↓
驗證來源清單
  ↓
建立 daily task id
  ↓
建立 task 目錄
  ↓
取得 output root
  ↓
檢查剩餘空間 > 1GB
  ↓
產生 task-envelope.json
  ↓
產生 execution-manifest.json
  ↓
呼叫 /srv/twitch-worker/bin/run-twitch-archive
  ↓
runner 依 manifest 執行 yt-dlp
  ↓
依 download archive 去重
  ↓
套用 1080p / 720p 畫質策略
  ↓
產出 result.json / download-report.json / logs
  ↓
Hermes 驗收 task artifacts
  ↓
必要時透過 Discord 通知
```

## 7. daily task id 規則

Hermes 每日正式下載任務必須建立 task id。

格式：

```text
TWITCH-DAILY-VOD-ARCHIVE-YYYYMMDD-NNN
```

範例：

```text
TWITCH-DAILY-VOD-ARCHIVE-20260809-001
```

task id 必須寫入：

1. `task-envelope.json`
2. `execution-manifest.json`
3. `result.json`
4. `download-report.json`
5. Hermes 狀態資料庫
6. Discord 通知內容

---

## 8. execution-manifest.json 正式格式

正式下載任務的 `execution-manifest.json` 至少包含：

```json
{
  "project": "twitch-archive",
  "context_root": "Twitch下載",
  "task_id": "TWITCH-DAILY-VOD-ARCHIVE-YYYYMMDD-NNN",
  "task_type": "phase_2_formal_daily_vod_download",
  "worker_id": "PI16G001",
  "runner_path": "/srv/twitch-worker/bin/run-twitch-archive",
  "timezone": "Asia/Taipei",
  "real_download_allowed": true,
  "dry_run": false,
  "source_count": 1,
  "sources": [
    {
      "source_id": "example_channel_vods",
      "channel_name": "example_channel",
      "source_url": "https://www.twitch.tv/example_channel/videos",
      "source_type": "channel_videos"
    }
  ],
  "video_quality_mode": "1080p",
  "target_height": 1080,
  "fallback_quality_mode": "720p",
  "fallback_height": 720,
  "if_1080p_unavailable": "fallback_to_720p",
  "if_1080p_and_720p_unavailable": "notify_user_and_end_daily_job",
  "allow_below_720p_fallback": false,
  "chat_archive_enabled": false,
  "video_retention_mode": "keep_forever_until_user_deletes",
  "auto_delete_videos": false,
  "low_disk_space_threshold_gb": 1,
  "notification_channel": "discord_via_hermes_existing_binding"
}
```

manifest 不得包含：

1. Discord webhook。
2. Twitch OAuth token。
3. cookie。
4. password。
5. 任何 secret。
6. `note` 中的私密資訊。

## 9. yt-dlp 正式下載規則

runner 必須從 manifest 組合 yt-dlp 命令。

不得把以下資訊硬編碼在 runner：

1. Twitch 來源。
2. output root。
3. 畫質策略。
4. Discord 通知目標。
5. retention 策略。
6. chat archive 策略。

正式下載必須使用 download archive 去重：

```text
/var/lib/twitch-archiver/archive.txt
```

正式下載必須寫出：

```text
--write-info-json
--write-thumbnail
--continue
--no-overwrites
--download-archive
--merge-output-format mp4
```

不得加入任何 chat 下載參數。

---

## 10. 畫質處理規則

畫質策略以 `下載畫質設定.md` 為準。

目前規則：

```yaml
quality_policy:
  primary: "1080p"
  fallback: "720p"
  if_1080p_unavailable: "fallback_to_720p"
  if_1080p_and_720p_unavailable: "notify_user_and_end_daily_job"
  allow_below_720p_fallback: false
```

runner 發現某支影片同時沒有 1080p 與 720p 時，必須：

1. 停止當天作業。
2. 不下載 480p 或更低畫質。
3. 不繼續處理當天剩餘來源或影片。
4. 透過 Hermes 既有 Discord 綁定通知使用者。
5. 將任務狀態寫為：

```text
ended_for_day_quality_unavailable
```

6. 在 `download-report.json` 中記錄來源、影片、可用畫質、目標畫質、fallback 畫質與通知狀態。

---

## 11. 磁碟空間規則

正式下載前必須檢查 output root 剩餘空間。

門檻：

```yaml
min_free_space_gb: 1
```

若剩餘空間低於 1GB，Hermes 必須：

1. 停止任務。
2. 不下載任何新影片。
3. 不自動刪除既有影片。
4. 透過 Hermes 既有 Discord 綁定通知使用者。
5. 回報：

```text
blocked_low_disk_space
```

---

## 12. 去重規則

正式下載必須使用 yt-dlp download archive。

目的：

1. 避免重複下載已保存影片。
2. 支援每日重跑。
3. 支援任務中斷後續傳。

若影片已存在於 archive，runner 必須略過並在 report 中記錄：

```text
skipped_already_archived
```

不得因檔案名稱不同就重複下載同一 Twitch VOD。

---

## 13. 單一影片失敗規則

若單一影片下載失敗，且不是畫質不可用、磁碟不足、來源錯誤或 secret 風險，runner 可繼續處理其他影片。

失敗項目必須寫入：

```text
failed-items.json
```

狀態碼：

```text
single_video_failed_continue
```

若失敗比例過高，Hermes 可在任務結束後發送摘要通知，但不得自行降低畫質或改變來源。

## 14. 必要任務產物

每次正式任務至少產生：


## 17. 通知規則

正式下載時，以下情況必須透過 Hermes 既有 Discord 綁定通知使用者：

1. 剩餘空間低於 1GB。
2. 來源清單為空。
3. 所有來源都未啟用或未確認。
4. 偵測到 secret。
5. 同時沒有 1080p 與 720p 可下載版本。
6. output root 不可用。
7. runner 或 yt-dlp 不可用。
8. 任務整體失敗。

以下情況可依 Hermes runtime 設定發送摘要通知：

1. 任務成功完成。
2. 任務成功但有單一影片失敗。
3. 任務沒有新影片可下載。

通知不得包含 secret。

## 19. 成功判定

正式每日下載任務成功不一定代表有下載到新影片。

以下都可算成功：

1. 有新影片並成功下載。
2. 沒有新影片，且確認沒有錯誤。
3. 部分影片失敗，但其餘影片依策略完成，且失敗項目已完整記錄。

但以下不得算成功：

1. 來源清單為空。
2. 來源未確認。
3. 剩餘空間低於 1GB。
4. 同時沒有 1080p 與 720p 可下載版本。
5. output root 不可用。
6. runner 不存在或不可執行。
7. 需要 secret 才能下載。

---

## 20. 禁止行為

Hermes / Agent / Worker / runner 在第二部分中不得：

1. 猜測、搜尋或自行新增 Twitch 來源。
2. 下載未列入 `TWITCH_CHANNEL_SOURCES` 的來源。
3. 下載 `authorization_status` 不是 `user_confirmed` 的來源。
4. 下載 Twitch chat。
5. 自動刪除已下載影片。
6. 因磁碟不足自行刪除影片。
7. 因網路慢自行降低畫質。
8. 因沒有 1080p / 720p 自行下載 480p 或更低畫質。
9. 保存 secret。
10. 修改其他根目錄文件或引用其他根目錄決策。
11. 在 report 中寫入 webhook、token、cookie 或 password。

---

## 21. 給 Hermes 的第二部分啟動指令範本

當 Hermes 已回報 `ready_for_channel_sources`，且使用者已填入並驗證 `TWITCH_CHANNEL_SOURCES` 後，可交給 Hermes：

```text
請執行 Twitch下載 第二部分正式每日下載功能。

請先讀取：
Twitch下載/第二部分正式每日下載功能規格.md

並依該文件重新讀取所有必讀文件、驗證 TWITCH_CHANNEL_SOURCES、確認 bootstrap / preflight / runner / dry-run 已通過。

若條件全部通過，才允許建立正式每日 Twitch VOD 下載任務。

不得下載聊天紀錄，不得自動刪除影片，不得自行降低到 480p 或更低畫質，不得保存任何 secret。
```

---

## 22. 最終判定

第二部分的完成目標是：

```text
Hermes 可以在來源清單已填且驗證通過後，每天定時下載指定 Twitch VOD，避免重複下載，套用 1080p / 720p 畫質策略，保留影片與 metadata，產生完整報告，並在需要時透過 Discord 通知使用者。
```

第二部分不會讓 Hermes 擁有新增來源、刪除影片、保存聊天紀錄、保存 secret 或自行變更畫質策略的權限。
