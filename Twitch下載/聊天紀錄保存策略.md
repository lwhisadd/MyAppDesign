# Twitch 聊天紀錄保存策略

> 適用範圍：`Twitch下載/` 獨立專案。  
> 決策狀態：已確認。  
> 使用者決策：A，只下載影片，不保存聊天紀錄。  
> 建立日期：2026-08-09

---

## 1. 決策結論

本專案目前只下載 Twitch 影片本體，不保存 Twitch 聊天紀錄。

Agent / Hermes / Worker / runner 必須遵守：

1. 不得啟用 Twitch chat downloader。
2. 不得產生 chat replay、chat json、chat log、chat subtitle 或 chat sidecar 檔案。
3. 不得因為工具支援聊天紀錄，就自行加入聊天紀錄下載流程。
4. 若未來需要保存聊天紀錄，必須先取得使用者明確指示，並更新本文件。

---

## 2. 任務變數

```yaml
TWITCH_CHAT_ARCHIVE_POLICY:
  # 是否保存 Twitch 聊天紀錄。
  # 使用者決策：A，只下載影片，不保存聊天紀錄。
  save_chat: false

  # 是否允許 runner 呼叫任何 chat downloader。
  # 行為：false 表示 runner 不得呼叫 Twitch chat replay / chat download 工具。
  enable_chat_downloader: false

  # 是否允許產生聊天 sidecar 檔案。
  # 行為：false 表示不得產生 .chat.json、.chat.txt、.chat.vtt、.chat.ass 等檔案。
  write_chat_sidecar: false

  # 是否允許 Agent 自行改成保存聊天紀錄。
  # 行為：false 表示需要使用者明確新指示後才可變更。
  agent_may_enable_without_user_confirmation: false

  # 若工具預設支援 chat，runner 應如何處理。
  # 行為：必須關閉或不啟用聊天下載參數。
  if_downloader_supports_chat: "disable_chat_download"

  # 任務報告中應記錄的聊天紀錄狀態。
  # 用途：result.json / download-report.json 應明確寫出 chat_archive=false，避免日後誤判。
  report_value: "chat_archive_disabled_by_user_decision"
```

---

## 3. Agent 執行規則

Agent 在建立 `execution-manifest.json` 時，必須加入：

```json
{
  "chat_archive": false,
  "chat_archive_policy": "chat_archive_disabled_by_user_decision"
}
```

runner 執行完畢後，`result.json` 與 `download-report.json` 必須包含：

```json
{
  "chat_archive_enabled": false,
  "chat_files_written": 0
}
```

---

## 4. 允許保存的非聊天資料

本決策只禁止 Twitch 聊天紀錄，不禁止下列資料：

- 影片檔案
- `info.json` metadata
- thumbnail
- 下載報告
- 任務 log
- 去重用 archive 狀態檔

若 metadata 內包含平台提供的基本影片資訊，仍可依主設定檔保存。
