# Twitch 影片保留策略

> 適用範圍：`Twitch下載/` 獨立專案。  
> 決策狀態：已確認。  
> 使用者決策：A，永久保存，除非使用者手動刪除。  
> 建立日期：2026-08-09

---

## 1. 決策結論

本專案下載完成的 Twitch 影片採用「永久保存」策略。

除非使用者明確手動刪除，或使用者未來明確修改本策略，Hermes / Agent / Worker / runner 不得自動刪除已下載影片。

---

## 2. 任務變數

```yaml
TWITCH_VIDEO_RETENTION_POLICY:
  # 影片保留模式。
  # 使用者決策：A，永久保存，除非使用者手動刪除。
  retention_mode: "keep_forever_until_user_deletes"

  # 是否啟用固定天數保留。
  # 行為：false 表示不因影片年齡自動刪除。
  enable_age_based_cleanup: false

  # 固定保留天數。
  # 行為：null 表示沒有固定天數上限。
  retention_days: null

  # 是否啟用磁碟空間不足時自動刪除。
  # 行為：false 表示即使磁碟空間不足，也只通知並阻擋任務，不自動清理影片。
  enable_free_space_cleanup: false

  # 是否允許 Agent 自行刪除已下載影片。
  # 行為：false 表示 Agent 必須取得使用者明確指示才可刪除影片。
  agent_may_delete_videos_without_user_confirmation: false

  # 磁碟空間不足時的處理。
  # 關聯：主設定檔中的 notification.low_disk_space 與 failure_policy。
  # 行為：通知使用者、阻擋任務、不自動刪檔。
  if_disk_space_low: "notify_user_and_block_task_without_deleting_videos"

  # 任務報告中應記錄的保留策略。
  # 用途：result.json / download-report.json 應明確寫出目前為永久保存策略。
  report_value: "retention_keep_forever_until_user_deletes"
```

---

## 3. Agent 執行規則

Agent 在建立 `execution-manifest.json` 時，必須加入：

```json
{
  "video_retention_mode": "keep_forever_until_user_deletes",
  "auto_delete_videos": false,
  "cleanup_requires_user_confirmation": true
}
```

runner 執行完畢後，`result.json` 與 `download-report.json` 必須包含：

```json
{
  "video_retention_mode": "keep_forever_until_user_deletes",
  "videos_deleted_by_task": 0,
  "auto_cleanup_enabled": false
}
```

---

## 4. 禁止行為

除非使用者未來明確授權，Agent / Hermes / Worker / runner 不得：

1. 依影片年齡自動刪除影片。
2. 依磁碟空間不足自動刪除最舊影片。
3. 依頻道自動清理影片。
4. 在任務失敗時刪除已完成下載的影片。
5. 將清理策略寫入 script、prompt、systemd unit 或 execution manifest 而未同步更新本文件。

---

## 5. 與低磁碟空間策略的關係

本專案已決定：剩餘空間低於 1GB 時，透過 Hermes 既有 Discord 綁定通知使用者、阻擋任務、不自動刪檔。

因此即使磁碟空間不足，也不得因為保留策略而自動刪除影片。清理磁碟空間必須由使用者手動處理，或由使用者另行明確授權新的清理策略。
