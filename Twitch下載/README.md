## 1. 專案目的

本目錄用於設計與管理一個獨立專案：

**利用 Raspberry Pi 5 `PI16G001` 每天定時下載 Twitch 影片，並由 Hermes agent 管理任務生命週期。**

本專案目前聚焦於：

1. Twitch VOD 定時下載。
2. Hermes agent 任務管理。
3. PI16G001 作為下載 worker。
4. 下載來源、排程、儲存與任務產物的變數化管理。
5. 避免將頻道、路徑、排程硬編碼到 script 或 prompt。
