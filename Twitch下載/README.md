> 除非使用者明確要求跨目錄比較，Agent 不得將其他目錄的技術決策自動套用到本目錄。

---

## 1. 專案目的

本目錄用於設計與管理一個獨立專案：

**利用 Raspberry Pi 5 `PI16G001` 每天定時下載 Twitch 影片，並由 Hermes agent 管理任務生命週期。**

本專案目前聚焦於：

1. Twitch VOD 定時下載。
2. Hermes agent 任務管理。
3. PI16G001 作為下載 worker。
4. 下載來源、排程、儲存與任務產物的變數化管理。
5. 避免將頻道、路徑、排程硬編碼到 script 或 prompt。
6. 明確禁止未授權保存 Twitch 聊天紀錄。
7. 明確禁止未授權自動刪除已下載影片。
8. 下載畫質以變數設定；目前優先 1080p，若無 1080p 則 fallback 到 720p；若同時沒有 1080p 與 720p，通知並結束當天作業。
9. 定義 Hermes 從套件安裝、runner 產生到每日下載驗收的自主佈建與執行流程。

## 5. 已確認決策

- Twitch 影片下載工作由 Hermes agent 管理。
- Twitch 頻道來源、排程、存放路徑、磁碟門檻與通知策略均以文件變數為準。
- 剩餘空間低於 1GB 時，透過 Hermes 既有 Discord 綁定通知使用者。
- 目前只下載影片，不保存 Twitch 聊天紀錄。
- 已下載影片永久保存，除非使用者手動刪除；Hermes / Agent / Worker / runner 不得自動刪除影片。
- 下載畫質優先 1080p；若來源沒有 1080p，fallback 到 720p。
- 若來源同時沒有 1080p 與 720p，透過 Hermes 既有 Discord 綁定通知使用者，並結束當天作業；不得自行下載 480p 或更低畫質。
- Hermes 可依 `Hermes自主佈建與執行規格.md` 在 PI16G001 上執行 allowlist 內的套件安裝、目錄建立、runner 產生、dry-run 與每日任務驗收。
- 若尚未完成 bootstrap、preflight、runner、dry-run 與通知能力驗收，Hermes 只能視為具備規劃能力，不可視為已具備完整自主執行能力。
