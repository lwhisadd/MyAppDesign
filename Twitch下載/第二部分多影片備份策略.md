# 第二部分：多影片備份策略

> 適用範圍：`Twitch下載/` 獨立專案。  
> 功能階段：第二部分 YouTube 頻道備份。  
> 決策狀態：已確認。  
> 建立日期：2026-08-09  
> 建立時區：Asia/Taipei

---

## 1. 使用者決策

使用者已確認：

```text
A. 如果最近一次任務產生多支影片，全部都要備份到指定 YouTube 頻道。
```

---

## 2. 決策結論

第二部分 YouTube 備份的影片選取規則如下：

```yaml
PHASE_2_MULTI_VIDEO_BACKUP_POLICY:
  youtube_backup_selection_mode: "latest_task_generated_videos"
  if_latest_task_generates_multiple_videos: "upload_all_eligible_videos"
  allow_upload_first_video_only: false
  allow_upload_primary_video_only: false
  allow_manual_selection_without_policy_update: false
```

也就是：

1. 第二部分只處理最近一次任務產生的影片。
2. 如果最近一次任務產生多支影片，Hermes 必須嘗試備份全部符合條件的影片。
3. Hermes 不得只備份第一支。
4. Hermes 不得只備份所謂主要影片。
5. Hermes 不得自行挑選部分影片。
6. 若未來要改成只備份部分影片，必須先更新本文件。

---

## 3. 合格影片定義

Hermes 只需要備份符合以下條件的影片：

```yaml
ELIGIBLE_LATEST_TASK_VIDEO:
  generated_by_latest_task: true
  local_file_exists: true
  local_file_is_video: true
  file_extension_allowed: true
  file_size_greater_than_zero: true
  file_not_still_being_written: true
  not_already_uploaded_to_youtube: true
```

不符合條件的影片可以略過，但必須寫入 report，並記錄 skipped reason。

---

## 4. 多影片處理流程

當最近一次任務產生多支影片時，Hermes 必須：

```text
讀取最近一次任務產物
  ↓
列出所有最近一次任務產生的影片
  ↓
逐一驗證影片是否符合 YouTube 備份條件
  ↓
排除已上傳或不合格影片
  ↓
將全部合格影片加入 youtube-backup-manifest.json
  ↓
逐一上傳到指定 YouTube 頻道
  ↓
每支影片都記錄 youtube video id 或失敗原因
  ↓
更新 youtube-upload-archive.jsonl
  ↓
產生 youtube-backup-result.json 與 youtube-backup-report.json
```

---

## 5. 部分成功處理

若多支影片中有部分上傳成功、部分上傳失敗，Hermes 必須：

1. 保留已成功上傳影片的 YouTube video id。
2. 將失敗影片寫入 `youtube-failed-items.json`。
3. 不得刪除本機影片。
4. 不得重複上傳已成功影片。
5. 停止後續 Twitch 下載。
6. 透過 Hermes 既有 Discord 綁定通知使用者。
7. 回報：

```text
blocked_youtube_backup_partial_failure_before_twitch_download
```

第二部分只有在全部合格影片都成功上傳，或沒有任何待備份影片時，才允許後續 Twitch 下載。

---

## 6. 任務結果統計欄位

`youtube-backup-result.json` 必須包含：

```json
{
  "youtube_backup_selection_mode": "latest_task_generated_videos",
  "if_latest_task_generates_multiple_videos": "upload_all_eligible_videos",
  "latest_task_videos_total": 0,
  "eligible_videos_total": 0,
  "videos_uploaded": 0,
  "videos_skipped": 0,
  "videos_failed": 0,
  "all_eligible_videos_uploaded": false,
  "twitch_download_allowed_after_backup": false
}
```

---

## 7. 禁止行為

Hermes / Agent / Worker / runner 不得：

1. 在最近一次任務產生多支影片時只備份第一支。
2. 在最近一次任務產生多支影片時只備份主要影片。
3. 自行選擇部分影片備份。
4. 在部分影片備份失敗後繼續 Twitch 下載。
5. 因為影片數量多就自動跳過部分影片。
6. 未更新本文件就改成手動挑選或單支影片模式。

---

## 8. 已確認事項

- 第二部分輸出目的地是指定 YouTube 頻道。
- 第二部分只處理最近一次任務產生的影片。
- 如果最近一次任務產生多支影片，全部符合條件者都要備份。
- 只有全部合格影片都備份成功，或沒有待備份影片時，才允許後續 Twitch 下載。
