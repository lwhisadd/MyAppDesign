# 第二部分：部分上傳失敗處理策略

> 適用範圍：`Twitch下載/` 獨立專案。  
> 功能階段：第二部分 YouTube 頻道備份。  
> 決策狀態：已確認。  
> 建立日期：2026-08-09  
> 建立時區：Asia/Taipei

---

## 1. 使用者決策

使用者已確認：

```text
B. 如果多支影片中有一支上傳 YouTube 失敗，不停止後續 Twitch 下載；成功的照算，失敗的通知，但仍繼續 Twitch 下載。
```

---

## 2. 決策結論

第二部分 YouTube 備份的部分失敗處理規則如下：

```yaml
PHASE_2_PARTIAL_UPLOAD_FAILURE_POLICY:
  if_some_videos_upload_success_and_some_fail: "continue_twitch_download_after_notification"
  successful_uploads_count_as_backed_up: true
  failed_uploads_must_be_reported: true
  failed_uploads_must_notify_user: true
  block_twitch_download_on_partial_upload_failure: false
  retry_failed_items_automatically_without_policy: false
```

也就是：

1. 如果最近一次任務產生多支影片，Hermes 仍應嘗試備份全部符合條件的影片。
2. 若其中部分影片成功、部分影片失敗，成功的上傳結果仍然算數。
3. 失敗影片必須寫入 report。
4. 失敗影片必須透過 Hermes 既有 Discord 綁定通知使用者。
5. 部分失敗不阻擋後續 Twitch 下載。
6. Hermes 不得自動重試無限次，也不得因失敗自行改變 YouTube metadata、隱私設定或影片來源。

## 4. 仍然會阻擋後續 Twitch 下載的情況

以下是 phase-level blocker，不屬於「部分影片上傳失敗」：

1. YouTube OAuth runtime 不可用。
2. YouTube 目標頻道未設定。
3. 找不到最近一次任務產物。
4. 無法讀取最近一次任務產物。
5. youtube upload archive 完全無法寫入。
6. Hermes 無法判斷哪些影片成功、哪些失敗。
7. 偵測到 token、cookie、password 或其他 secret 被寫入 manifest/report/log。

遇到以上情況，Hermes 必須停止後續 Twitch 下載並通知使用者。

---

## 5. 部分失敗時的任務狀態

如果至少一支影片成功上傳，且至少一支影片上傳失敗，Hermes 應回報：

```text
succeeded_with_youtube_upload_failures
```

此狀態代表：

1. YouTube 備份流程已執行。
2. 部分影片已成功備份。
3. 部分影片未成功備份。
4. 使用者已被通知。
5. 後續 Twitch 下載可以繼續。

---

## 6. result.json 欄位

`youtube-backup-result.json` 必須包含：

```json
{
  "status": "succeeded_with_youtube_upload_failures",
  "videos_uploaded": 0,
  "videos_failed": 0,
  "failed_uploads_notified": true,
  "twitch_download_allowed_after_backup": true,
  "partial_failure_policy": "continue_twitch_download_after_notification"
}
```

---

## 7. report 要求

部分失敗時，Hermes 必須在 report 中列出：

1. 成功上傳的影片清單。
2. 每支成功影片的 YouTube video id。
3. 失敗影片清單。
4. 每支失敗影片的失敗原因。
5. 是否已通知使用者。
6. 是否允許後續 Twitch 下載。

---

## 8. 禁止行為

Hermes / Agent / Worker / runner 不得：

1. 因為單一影片上傳失敗就停止後續 Twitch 下載。
2. 把部分失敗誤報為全部成功。
3. 忽略失敗影片不通知使用者。
4. 重複上傳已成功影片。
5. 為了修復失敗而自動修改 YouTube 隱私設定。
6. 為了修復失敗而自動換 YouTube 目標頻道。
7. 把 YouTube OAuth token、refresh token、client secret 寫入任何 repo、manifest、report、log 或 Discord 通知。

---

## 9. 已確認事項

- 最近一次任務產生多支影片時，全部符合條件者都要嘗試備份。
- 若部分成功、部分失敗，成功的照算。
- 失敗的必須通知並寫入 report。
- 部分失敗不阻擋後續 Twitch 下載。
- phase-level blocker 仍會阻擋後續 Twitch 下載。
