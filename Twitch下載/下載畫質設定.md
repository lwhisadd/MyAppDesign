# Twitch 下載畫質設定

> 適用範圍：`Twitch下載/` 獨立專案。  
> 決策狀態：已確認目標畫質，fallback 行為待確認。  
> 使用者決策：下載畫質設定為 1080p，且必須設定成變數，不得硬編碼。  
> 建立日期：2026-08-09
> 最近更新：2026-08-09，設定目標下載畫質為 1080p。

---

## 1. 決策結論

本專案的 Twitch 下載畫質必須設定成變數。

使用者已指定目標下載畫質為 **1080p**。

Agent / Hermes / Worker / runner 不得把畫質選擇硬編碼在 prompt、shell script、systemd unit 或 execution manifest 中。

目前已確認目標畫質為 1080p；但若 Twitch 來源沒有 1080p 可下載版本時，是否允許降級到其他畫質，尚未確認。因此 fallback 行為仍標示為 `to_be_confirmed`。

---

## 2. 任務變數

```yaml
TWITCH_VIDEO_QUALITY_POLICY:
  # 畫質設定狀態。
  # 用途：提醒 Agent 目前已確認目標畫質為 1080p，但 fallback 行為尚待使用者確認。
  configuration_status: "configured_with_fallback_to_be_confirmed"

  # 下載畫質模式。
  # 使用者決策：1080p。
  # 行為：runner 應以 1080p 作為目標下載畫質。
  quality_mode: "1080p"

  # 目標解析度高度。
  # 用途：讓 runner 與報告用結構化數值表示 1080p。
  target_height: 1080

  # yt-dlp format selector。
  # 用途：runner 實際呼叫 yt-dlp 時使用的格式選擇器。
  # 狀態：因 fallback 行為尚未確認，暫不填入最終 selector，避免 Agent 擅自決定「允許低於 1080p」或「必須精準 1080p」。
  ytdlp_format_selector: "to_be_confirmed_after_fallback_policy"

  # 是否允許 Agent 自行選最高畫質。
  # 行為：false 表示不得把 1080p 改成 best / source / highest。
  agent_may_assume_best_quality: false

  # 是否允許 Agent 自行降低畫質以節省空間。
  # 行為：false 表示不得因磁碟空間或速度自行改成 720p / 480p。
  agent_may_lower_quality_without_user_confirmation: false

  # 若來源沒有 1080p 時的處理。
  # 狀態：待使用者確認。
  # 下一步需要決定：A. 不下載該影片；B. 允許下載低於 1080p 的最佳版本；C. 只通知使用者。
  if_1080p_unavailable: "to_be_confirmed"

  # 若畫質 fallback 尚未設定時的處理。
  # 行為：建立正式下載任務前應回報需要使用者確認 fallback 行為。
  if_quality_fallback_not_configured: "requires_user_input"

  # 任務報告中應記錄的畫質設定狀態。
  # 用途：result.json / download-report.json 應記錄實際使用的 quality_mode、target_height 與實際下載高度。
  report_required: true
```

---

## 3. Agent 執行規則

Agent 在建立 `execution-manifest.json` 時，必須加入畫質設定欄位。

若 fallback 行為尚未設定，manifest 不得偽造預設值，應標示：

```json
{
  "video_quality_configuration_status": "configured_with_fallback_to_be_confirmed",
  "video_quality_mode": "1080p",
  "target_height": 1080,
  "quality_fallback_policy": "to_be_confirmed",
  "requires_user_input": true
}
```

若未來使用者指定 fallback 行為，Agent 必須更新本文件，並在 manifest 中寫入實際值。

---

## 4. 禁止行為

除非使用者明確指定，Agent / Hermes / Worker / runner 不得：

1. 自行把 1080p 改成最高畫質、source 或 best。
2. 自行假設沒有 1080p 時可以下載 720p、480p 或其他畫質。
3. 自行假設沒有 1080p 時應跳過影片。
4. 自行把 yt-dlp format selector 寫死在 runner。
5. 因磁碟空間不足自行降低畫質。
6. 因網路速度自行降低畫質。
7. 未更新本文件就更改 execution-manifest.json 中的畫質策略。

---

## 5. 待確認事項
